# 仿真与 RSI 工作台

聊天 TUI 顶部的「仿真工作台」、**F3** 或 `/workbench` 打开工作台。
`/rsi` 直接进入策略与修订页。也可以独立运行：

```bash
physicsos workbench
physicsos workbench --workspace /path/to/workspace
```

独立工作台无需启动模型服务或配置 API Key。它使用当前 PhysicsOS 工作区
中的真实案例、策略、评估和证据文件。

## 案例与运行

列表展示几何准备、求解、独立验证与细化检查。可按案例名、类型或状态筛选。
执行成功、验证通过、证据不足以及后端不可用分别显示；选择记录并按 Enter
或点击该行，进入验证证据页。

## RSI 策略与修订

列表展示已登记的策略版本、基准集、修订 provider、自动修订记录、候选评估
和晋升/回滚记录。默认策略标明登记表的当前版本和证据完整性。

自动修订表单选择已登记的基准集、修订 provider 和初始策略，设置修订轮数、
求解预算与单步超时。可选择只使用开发集，或完成保留集检查后自动晋升。
策略、物理问题与参考实现由聊天 agent 或 [RSI 注册接口](rsi.md) 准备。

「查看能力」读取所选策略或基准范围的独立成功记录和能力估计。
「晋升评估」仅对可晋升的评估启用；「回滚默认」仅对当前默认策略启用。
所有操作复用 RSIRuntime，重新检查证据与登记表版本。

长任务在后台执行，页面保持可浏览并刷新新求解记录。任务执行时禁止重复提交；
在本次任务结束后可返回聊天。聊天中的 agent 正在操作工作区时，工作台仍可
浏览记录，启动任务或改变默认策略需等待当前操作结束。

## 验证证据

页面显示所选记录的质量检查、验证误差、收敛数据或修订预算摘要，并列出关联
产物及其校验状态。可选择 JSON、Markdown、日志或 Python 文件查看文本。
网格与数组文件显示本地路径，便于使用相应查看器打开。

缺失、损坏或校验不一致的证据会显示待检查状态。工作台不会替换数值验证。
**F5** 刷新记录；**Esc** 返回聊天或退出独立工作台。
